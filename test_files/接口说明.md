# APQP 标准 AI 评分接口

**接口地址**  
`POST http://192.168.0.100:8000/api/v1/question_with_file`

**功能说明**  
上传文件，AI 根据用户指定的评分要求对文件内容进行自动评审打分。支持两种调用模式：

- **同步模式**：不传 `callback_url`，阻塞等待评分完成后直接返回结果。
- **异步模式**：传入 `callback_url`，立即返回任务序号 `seq_id`，评分完成后通过 HTTP POST 回调推送结果。

---

## 请求方式

- **方法**：`POST`
- **Content-Type**：`multipart/form-data`

---


## 调用示例

### cURL - 同步模式

```bash
curl -X POST "http://192.168.0.100:8000/api/v1/question_with_file" \
  -F "file=@/path/to/document.pdf" \
  -F "question=请从内容完整性、格式规范性、逻辑清晰度三个维度打分，每项满分100分"
```

响应示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "answer": "### 评审结果\n\n**1. 内容完整性 (100分)**\n- 得分: 85\n- 理由: ..."
  }
}
```

### cURL - 异步模式

```bash
curl -X POST "http://192.168.0.100:8000/api/v1/question_with_file" \
  -F "file=@report.docx" \
  -F "question=评估报告的专业性和数据准确性，各50分" \
  -F "callback_url=https://your-server.com/callback"
```

响应（立即返回）：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "seq_id": "APQP260708153045"
  }
}
```
